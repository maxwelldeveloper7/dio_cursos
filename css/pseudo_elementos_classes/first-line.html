Pseudo-elementos

Usado para adicionar elementos extras na página, sem a necessidade de decralá-lo no HTML, ou para selecionar uma parte de algum elemento.

Identificado por ::palavra-chave

Pseudo-elemento - ::first-liner

Selecina a primeira linha de um texto

Propriedades disponíveis:

  • color
  • background
  • font
  • Propriedades de texto
